# Parking Pal

Apps in Toss에 배포할 모바일 미니앱 **“여기주차”**의 UI/UX 프로토타입을 제작해줘.

서비스 정의

“여기주차”는 현재 위치 또는 사용자가 검색한 목적지 주변의 주차장을 찾아, 예상 주차시간을 기준으로 가까운 곳 / 가장 저렴한 곳 / 종합 추천 주차장을 빠르게 보여주는 서비스다.

사용자가 이미 다른 장소에 주차한 경우에는 주차 타이머를 독립적으로 시작해 무료 주차시간과 예상 주차비를 관리할 수 있다.

디자인 목표

모바일 우선으로 제작한다.

360~390px 폭에서 자연스럽게 보이도록 설계한다.

Apps in Toss 미니앱이므로 토스 계열의 깔끔하고 신뢰감 있는 모바일 UX를 참고하되, 토스 화면을 그대로 복제하지 않는다.

밝은 배경, 높은 정보 가독성, 충분한 여백, 둥근 카드, 절제된 아이콘을 사용한다.

메인 강조색은 선명한 블루 계열을 사용한다.

실시간 여유는 그린, 혼잡은 오렌지, 만차는 레드 등 상태의 의미가 명확하게 보이게 한다.

지도보다 사용자가 **“어디에 주차할지 빨리 결정하는 것”**이 우선이다.

첫 화면을 지도 풀스크린으로 만들지 말고 추천 카드 중심으로 구성한다.

한 손 조작을 고려해 주요 CTA는 화면 하단 가까이에 배치한다.

버튼은 불필요하게 화면 전체 폭을 꽉 채우는 거대한 형태로 만들지 말고 중요도에 맞게 적절한 크기와 여백을 둔다.

화면 상단은 Apps in Toss 기본 navigation bar가 존재한다고 가정하고 자체 상단바를 중복 구현하지 않는다.

MVP에서는 별도의 bottom tab bar를 만들지 않는다.

중요 디자인 원칙

데스크톱 대시보드처럼 만들지 않는다.

실제 스마트폰에서 사용하는 모바일 미니앱처럼 만든다.

카드가 지나치게 많거나 복잡하게 보이지 않게 한다.

지도 화면이 서비스를 지배하지 않게 한다.

사용자가 앱 진입 후 10초 안에 어디에 주차할지 판단할 수 있는 구조를 최우선으로 한다.

사용자가 이미 주차한 경우에는 홈에서 주차 타이머로 매우 빠르게 진입할 수 있어야 한다.

정보 밀도를 지나치게 높이지 않는다.

작은 텍스트를 과도하게 사용하지 않는다.

주요 터치 영역은 충분한 크기로 만든다.

iOS/Android 모바일 safe area를 고려한다.

Apps in Toss의 기본 상단 navigation 영역을 침범하지 않는다.

화면을 단순 이미지 시안으로 만들지 말고, 실제로 각 화면을 이동하고 버튼을 눌러볼 수 있는 프로토타입으로 연결한다.
